# Задание для агента

Ты — опытный fullstack-разработчик. Твоя задача — создать веб-приложение "Verbal Fluency Trainer" по спецификации из файла `verbal_fluency_trainer_concept.docx` в корне проекта.

## Контекст

Это приложение для ежедневной тренировки речевой беглости. Пользователь выполняет упражнения: говорит слова в микрофон, а приложение считает их, проверяет по правилам и показывает результат. Никакого бэкенда и AI API — всё работает в браузере.

В папке `/public/images/` лежат 250 контурных чёрно-белых картинок (PNG) для упражнения "Пикнейминг". Каждую картинку нужно будет подписать (маппинг имя файла → название на русском), но это сделаем отдельно.

## Что делаем сейчас — MVP (Фаза 1)

Начни с MVP: три упражнения, которые покрывают три типа интерфейса.

### Технологии

- React + Vite + TypeScript
- Tailwind CSS для стилей
- Dexie.js для хранения данных (IndexedDB)
- Web Speech API для распознавания речи (язык: ru-RU)
- Web Audio API для метронома
- Recharts для графиков (понадобится позже)

### Упражнение №1: Семантическая беглость

**Экран настройки:**
- Выпадающий список категорий: Животные, Фрукты, Овощи, Профессии, Транспорт, Еда и напитки
- Длительность: 30 / 45 / 60 / 90 секунд (по умолчанию 60)
- Метроном: вкл/выкл + ползунок bpm (30-120, по умолчанию 60)
- Кнопка "Старт"

**Экран тренировки:**
- Обратный отсчёт 3-2-1 перед стартом
- Крупный таймер по центру (моноширинный шрифт, формат 00:37)
- Красная пульсирующая точка "Запись"
- Зона распознанных слов: каждое слово — WordChip. Цвет определяется мгновенно:
  - Зелёный: слово найдено в словаре выбранной категории
  - Жёлтый: слово не найдено в словаре (может быть правильным, но словарь неполный)
  - Красный: повтор уже сказанного слова
- Счётчик слов внизу
- Метроном тикает в фоне (если включён)

**Экран результатов:**
- Итого: X слов, Y верных, Z под вопросом, W ошибок
- Список всех слов с цветовой маркировкой
- Жёлтые слова кликабельны: нажал = подтвердил (стал зелёным) или отклонил (стал красным)
- Итоговый балл = зелёные + подтверждённые
- Кнопки: "Ещё раз" / "Новые параметры" / "На главную"
- Результат сохраняется в IndexedDB

**ВАЖНО — Вердикт и шкала оценки:**

После подсчёта итогового балла (количество засчитанных слов за 60 секунд) приложение показывает вердикт — крупно, с цветом и иконкой. Шкала:

| 0–8 | Критический | Красный | «Критический уровень. Начните с медленного темпа, не спешите. Регулярные тренировки дадут результат.» |
| 9–12 | Низкий | Оранжевый | «Ниже среднего. Есть куда расти. Тренируйтесь ежедневно по 3–5 минут.» |
| 13–15 | Базовый | Жёлтый | «Базовый уровень. Вы на правильном пути. Стремитесь к 20+.» |
| 16–21 | Средний | Голубой | «Хороший средний уровень. Продолжайте тренировки для выхода на продвинутый.» |
| 22–30 | Хороший | Зелёный | «Отличный результат! Ваша семантическая беглость выше среднего.» |
| 31–40 | Продвинутый | Фиолетовый | «Продвинутый уровень! Переходите к более сложным упражнениям.» |

Ориентиры (показывать мелким текстом под вердиктом):
- «Средний показатель взрослого человека: ~22 слова/мин»
- «Показатель ниже 14 говорит о необходимости тренировок»
- «Показатель ниже 12 может указывать на сильные речевые блоки»

Также показывать сравнение с предыдущими результатами (если есть): «Прошлый раз: 14 → Сейчас: 18 (+4, рост 28%)» — зелёным, если рост, красным если падение.

Вердикт отображается в верхней части экрана результатов — крупным шрифтом, с цветным бейджем уровня. Под ним — ориентир. Ниже — детальный разбор слов.

**Словарь категорий (categories.ts):**

Пример для "Животные": кот, собака, лошадь, корова, медведь, волк, лиса, заяц, тигр, лев, слон, жираф, обезьяна, крокодил, черепаха, орёл, воробей, ворона, голубь, сова, лягушка, змея, акула, дельфин, кит... и так далее. ### Упражнение №2А: Фонетическая беглость

**Экран тренировки:**
- Такой же, как в №1, но проверка другая:

### Упражнение №3: Пикнейминг

**Экран настройки:**
- Скорость показа: 0.5 / 1 / 1.5 / 2 / 3 секунды на картинку
- Количество картинок: 10 / 20 / 30 / 50 / Все
- Кнопка "Старт"

**Экран тренировки:**
- Картинка по центру экрана (крупная, занимает ~60% высоты экрана)
- Прогресс-бар снизу (1/30)
- Микрофон записывает параллельно
- Картинки сменяются автоматически с заданной скоростью

**Логика проверки:**
- Пока маппинг картинок не создан, просто записывай распознанные слова с таймстемпами
- Когда маппинг будет готов (picnaming-map.json), сопоставляй: в момент показа картинки X пользователь сказал слово Y → проверить, совпадает ли Y с correctName или synonyms картинки X

**Экран результатов:**
- Таблица: миниатюра картинки | правильный ответ | что сказал | статус
- Итого: X из Y верно

**ВАЖНО — Вердикт и шкала оценки:**

Для пикнейминга оценка считается иначе: итоговый балл = количество правильных чётких ответов без задержек (>1.5 сек = задержка, не считается). Ошибки: бормотание, заполнялки «э-э-э», неправильное название, пропуск (молчание), задержка > 1.5 секунды.

Шкала (при 30 картинках по умолчанию):

| Балл | Уровень | Цвет | Сообщение |
|------|---------|------|-----------|
| 0–10 | Критический | Красный | «Критический уровень. Тренируйте сначала фонетическую беглость, потом возвращайтесь к пикнеймингу.» |
| 11–16 | Низкий | Оранжевый | «Ниже среднего. Увеличьте время показа картинки до 2–3 секунд и тренируйтесь.» |
| 17–21 | Базовый | Жёлтый | «Базовый уровень. Постепенно уменьшайте время показа.» |
| 22–25 | Средний | Голубой | «Хороший результат. Попробуйте ускорить показ до 1 секунды.» |
| 26–28 | Хороший | Зелёный | «Отлично! Быстрое распознавание и называние.» |
| 29–30 | Мастер | Золотой | «Безупречно! Мгновенная реакция на каждую картинку.» |

Ориентиры:
- «Счёт ниже 17 говорит о необходимости активных тренировок»
- «Пикнейминг тренирует связь "вижу → говорю" без задержки»
- «Обращайте внимание на эндокринную систему при стабильно низких результатах»

При масштабировании на другое количество картинок (10, 20, 50) — пересчитывать пороги пропорционально. Формула: порог = (порог_для_30 / 30) * количество_картинок, округлить.

Дополнительная статистика на экране результатов:
- Среднее время реакции (мс) — от показа картинки до начала произнесения слова
- Самая быстрая и самая медленная реакция
- Количество задержек (>1.5 сек)
- Количество пропусков (молчание)

**Комбинированный вердикт (после всех 3 упражнений MVP):**

Если пользователь в рамках одной дневной сессии выполнил и семантический тест, и фонетический тест — показать на Dashboard сводный вердикт:

«Ваши текущие показатели Вербального Флюенса:
- Семантическая беглость: 19 (Средний)
- Фонетическая беглость: 14 (Базовый)  
- Пикнейминг: 24/30 (Средний)
Общая рекомендация: подтяните фонетическую беглость — она отстаёт от семантической.»

### Общие компоненты

**Timer.tsx:**
- Принимает duration (секунды) и onComplete callback
- Показывает время в формате MM:SS
- Круговой SVG прогресс-бар вокруг цифр
- Методы: start(), pause(), resume(), stop()

**Metronome.tsx (useMetronome hook):**
- Генерирует короткий клик через Web Audio API (OscillatorNode, 80мс, 800Hz)
- Визуальная пульсация (CSS animation, мигание точки)
- Принимает bpm, isPlaying

**useSpeechRecognition hook:**
- Инициализирует webkitSpeechRecognition с lang='ru-RU', continuous=true, interimResults=true
- Возвращает: { transcript, words[], isListening, start(), stop() }
- words — массив объектов: { text: string, timestamp: number, isFinal: boolean }
- Обрабатывает ошибки (нет микрофона, нет разрешения, не поддерживается)

**WordChip.tsx:**
- Пропсы: word, status ('valid' | 'pending' | 'error'), errorReason?, onClick?
- Зелёный фон для valid, жёлтый для pending, красный для error
- При наведении на error показывает причину

**validators.ts:**

// Проверка первой буквы
